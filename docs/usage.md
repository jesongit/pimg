# 使用说明

## 上传和整理

管理员在后台创建普通账号，不提供游客注册。普通用户管理自己的文件、相册及账号安全，管理员可以按用户代管。存储连接、服务器导入与公开授权由管理员管理。

在图库点击「上传」，选择文件、目标相册和加密设置，再点击「开始上传」。拖入或粘贴只会预选，不立即上传。默认归入未分类，不永久发布。通过筛选、日期时间轴和多选批量整理；普通用户也能管理自己的相册，非空相册须先移走文件再删除。

## 公开与分享

| 方式 | 用途 | 访问边界 |
| --- | --- | --- |
| 首页公开 | 展示文件或相册 | 仅图片缩略图和视频静态封面 |
| 永久发布 | 获取公开原件外链 | 按永久发布状态独立授权，需单独撤销 |
| 临时链接 | 在有效期内访问查看副本 | 同时受副本保留期及链接有效期约束 |

管理员在详情「公开」，或多选后「批量公开」；也可以公开整个相册。公开相册内单独取消公开，只隐藏该文件，其他文件继续继承相册授权。单独公开文件不随相册取消公开而撤销。

公开缩略图不会改变原件的加密设置、归属或永久发布状态。撤销授权后新的请求会重新校验，已经加载到客户端的内容无法撤回。

## 查重

「查重」覆盖当前筛选的全部结果，包含尚未加载的分页，也可以跨相册。程序按类型比较图片画面或视频原文件大小。

相似图片提供差异核对；判断可靠时在右侧显示「建议保留」，判断不足时只排序。视频大小相同只表示需要核对，不代表内容相同。

扫描不会删除文件。选定保留项后仍需二次确认，服务端提交时复核两侧状态。两次独立点击可快速确认，首次点击不提交删除。

## 文件浏览与导入

管理员从顶部「文件」进入，默认打开配置的来源目录，并记住上次访问位置。通过文件夹和顶部可点击的路径逐级浏览，支持返回上一级、当前目录搜索和刷新；搜索旁可按名称、文件大小或文件类型（扩展名）升序／降序排列，文件夹始终在前，排序覆盖当前目录全部条目并沿用于加载更多；文件列表使用完整内容宽度，不另设路径输入框或目录侧栏。“上一级”图标右侧的“收藏夹”图标按钮展开菜单，每项只有文件夹名字和取消收藏图标；点击名字打开目录。路径右侧的星标按钮用于收藏或取消收藏当前目录，继续读取本浏览器按管理员账号保存的旧收藏。图库不再另设「导入」入口，普通账号不能访问服务器目录。

图片直接读取原文件，按可见范围加载；点击图片可放大、拖动或前后切换。视频点开后准备播放，支持进度拖动。浏览器不能直接观看的格式沿用 HEIC 解码、图片转换、视频重封装或转码，兼容版本按需产生在 PIMG 运行缓存中并自动过期，不预先生成整个目录的缩略图或视频封面。首次兼容处理可能需要等待；导入和原件下载始终使用源文件。

选中文件后点击「导入到相册」，选择目标用户的内部相册和加密选项，预览后再显式开始。支持多选、范围选择与滑选；全选作用于当前已加载且允许导入的文件，一次最多选择 200 项。导入整个文件夹时使用「导入当前目录」，可选择包含子目录和空闲处理。后台批次支持暂停、继续及失败重试，完成后可进入目标相册。

导入沿用已有内容去重：重复内容保留已有相册，结果会显示重复原因及所在相册，不自动移动已有文件。导入复制来源，保留原素材；删除 PIMG 内文件不会删除导入源。源目录没有改名、移动或删除入口。

Docker 需先只读挂载素材目录，例如 `-v /srv/photos:/media-source:ro`，可用 `-e PIMG_IMPORT_DIR=/media-source` 将其设为默认来源目录，再进入「文件」页浏览。未挂载的宿主目录不可访问；符号链接不列出或跟随。

## 账号安全与任务

管理员在「设置 → 账号安全」、普通用户在「账号安全」配置密码及可选 TOTP 两步验证。开启时保存一次性恢复码，验证器不可用时仍需密码与有效恢复码。

API 令牌与网页登录分别管理，不要放进公开链接。原件归档接口使用 `Authorization: Bearer <令牌>`，不能用游客首页权限代替。

处理中操作在任务页查看，终态记录在日志中；普通用户通过操作提示查看自己的进度，不获得管理任务页权限。
