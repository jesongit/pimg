# 使用说明

## 上传和整理

管理员在后台创建普通账号，不提供游客注册。普通用户管理自己的文件、相册及账号安全，管理员可以按用户代管。存储连接、服务器导入与公开授权由管理员管理。

在图库点击「上传」，选择文件、目标相册和加密设置，再点击「开始上传」。拖入或粘贴只会预选，不立即上传。默认归入未分类，不永久发布。通过筛选、日期时间轴和多选批量整理；普通用户也能管理自己的相册，非空相册须先移走文件再删除。

## 公开与分享

| 方式 | 用途 | 访问边界 |
| --- | --- | --- |
| 首页公开 | 展示文件或相册 | 仅图片缩略图和视频静态封面 |
| 永久发布 | 获取公开原件外链 | 按永久发布状态独立授权，需单独撤销 |
| 临时链接 | 在有效期内访问查看副本 | 同时受副本保留期及链接有效期约束 |

管理员在详情「公开」，或多选后「批量公开」；也可以公开整个相册。公开相册内单独取消公开，只隐藏该文件，其他文件继续继承相册授权。单独公开文件不随相册取消公开而撤销。

公开缩略图不会改变原件的加密设置、归属或永久发布状态。撤销授权后新的请求会重新校验，已经加载到客户端的内容无法撤回。

## 查重

「查重」覆盖当前筛选的全部结果，包含尚未加载的分页，也可以跨相册。程序按类型比较图片画面或视频原文件大小。

相似图片提供差异核对；判断可靠时在右侧显示「建议保留」，判断不足时只排序。视频大小相同只表示需要核对，不代表内容相同。

扫描不会删除文件。选定保留项后仍需二次确认，服务端提交时复核两侧状态。两次独立点击可快速确认，首次点击不提交删除。

## 文件浏览与导入

管理员从顶部「文件」进入，默认打开配置的来源目录，并记住上次访问位置。通过文件夹和顶部可点击的路径逐级浏览，支持返回上一级、搜索和刷新。文件夹与文件在同一张全宽详情列表中显示名称、类型、大小、文件系统创建时间和修改时间，手机将这些信息堆叠在同一条记录内；没有创建时间时显示“—”，不使用修改时间代替。点击表头或搜索旁排序菜单，可按这五项升序／降序排列，共十种排序；普通模式下文件夹在前，排序覆盖全部匹配条目并沿用于加载更多，未知创建时间始终置后。不另设路径输入框或目录侧栏。

路径左侧保留「上一级」「收藏夹」图标；路径右侧依次是「展开所有文件」、当前目录收藏星标和刷新。「展开所有文件」紧邻收藏星标左侧，点击后平铺当前目录及所有子目录中的图片和视频，嵌套文件显示相对文件夹，可继续搜索、排序、分页、选择及前后查看；再次点击恢复逐层浏览。文件系统根目录禁用展开；每次切换路径，包括上一级、祖先路径、收藏和浏览器历史导航，都会恢复逐层浏览，需要时再手动展开；同一目录刷新保留模式。递归模式不跟随符号链接，无法读取的子目录会显示提示；达到扫描数量、层级或元数据上限时展示已扫描结果并明确提示范围不完整，排序只覆盖本次已扫描范围，可进入更小的子文件夹查看完整内容。普通目录按所需分页范围保留排序结果，目录超过 5 万项时也可浏览首页。快照缓存有大小和时间上限；递归加载更多保留同次扫描的顺序，刷新会重新扫描。收藏菜单每项只有文件夹名字和取消收藏图标，点击名字打开目录；路径右侧的星标收藏或取消收藏当前目录，继续读取本浏览器按管理员账号保存的旧收藏。图库不再另设「导入」入口，普通账号不能访问服务器目录。

列表只加载文件信息，不读取原件、缩略图或视频封面。打开图片或视频时即开始加载源文件，无需再次点击加载；图片可放大、拖动或前后切换，视频支持进度拖动。支持 HEVC 的浏览器可直接播放 SDR、8 位 HEVC＋兼容音轨的 MP4/M4V，播放失败后自动选择兼容处理；不支持时仍生成兼容版本。浏览器不能直接观看的格式自动沿用 HEIC 解码、图片转换、视频重封装或转码，兼容版本按需产生在 PIMG 运行缓存中并自动过期。只有音轨不兼容时保留原画面，仅转换音轨；Linux 的视频兼容处理从经过校验的只读文件句柄读取，不先复制完整原件。准备时区分等待、复制、封装和转码，并显示实际转换进度；首次必要的转码仍可能需要等待，浏览器拒绝播放或读取失败时可重试。导入和原件下载始终使用源文件。

在「设置 → 文件索引」按行填写要监听的服务器／容器内绝对目录，保存后立即生效，包含子目录。默认为空，不监听、扫描或创建索引库；清空并保存停止全部监听。最多设置 16 个目录，重叠目录自动合并，不能监听文件系统根目录或包含 PIMG 数据／运行缓存的目录。Docker 中需先只读挂载来源。

首次建立索引在后台扫描文件信息，期间列表会提示尚不完整并自动更新。之后配置范围内的文件浏览、搜索、排序和展开直接查询持久化索引，分页只读取 200 项；单文件变化仅更新对应记录，新增目录扫描新增子树，移动和删除会同步移除旧索引。重启复用已建立的索引并后台校对；每 10 分钟全量校对一次，补上网络挂载可能漏掉的变更通知，也可在设置点击「更新索引」或在文件页刷新。索引仅存文件信息，不读取完整媒体、不转码、不导入。系统监听最多占用 8192 个目录句柄，更多目录继续进入索引并通过定期校对更新；状态异常会显示具体错误，未完整读取的目录保留原索引，不作为空目录删除。索引库位于运行目录的 `cache/browser-index.sqlite`，独立于图库数据库。

未配置的目录继续使用即时扫描及上述范围限制。索引中的展开不受即时扫描 5 万条限制；仍受 1 GiB 索引数据库空间、15 分钟单次校对时限及 128 层目录深度约束，失败时明确提示。索引变化后加载更多会要求刷新，避免分页错位；已选择文件、正在查看或已加载多页时不会强行替换当前列表。实际打开、下载和导入仍校验源文件版本和只读访问权限，索引不会放宽访问规则。兼容转码在 Linux 直接读取源文件，但首次仍需等兼容输出生成完成；目前不支持边转码边播放。

选中文件后点击「导入到相册」，选择目标用户的内部相册和加密选项，预览后再显式开始。支持多选、范围选择与滑选；全选作用于当前已加载且允许导入的文件，一次最多选择 200 项。导入整个文件夹时使用「导入当前目录」，可选择包含子目录和空闲处理。后台批次支持暂停、继续及失败重试，完成后可进入目标相册。

导入沿用已有内容去重：重复内容保留已有相册，结果会显示重复原因及所在相册，不自动移动已有文件。导入复制来源，保留原素材；删除 PIMG 内文件不会删除导入源。源目录没有改名、移动或删除入口。

Docker 需先只读挂载素材目录，例如 `-v /srv/photos:/media-source:ro`，可用 `-e PIMG_IMPORT_DIR=/media-source` 将其设为默认来源目录，再进入「文件」页浏览。未挂载的宿主目录不可访问；符号链接不列出或跟随。

## 账号安全与任务

管理员在「设置 → 账号安全」、普通用户在「账号安全」配置密码及可选 TOTP 两步验证。开启时保存一次性恢复码，验证器不可用时仍需密码与有效恢复码。

API 令牌与网页登录分别管理，不要放进公开链接。原件归档接口使用 `Authorization: Bearer <令牌>`，不能用游客首页权限代替。

处理中操作在任务页查看，终态记录在日志中；普通用户通过操作提示查看自己的进度，不获得管理任务页权限。
