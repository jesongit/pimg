# v1.0.47

修复日志页查询慢、HDR 视频播放卡顿与无法跳转，并为任务历史加上体积上限。

- 启动时压缩任务历史：每文件的归档同步记录只保留最近 5 条，其余连同操作任务、行修订和空同步操作一并删除。此前循环缺陷积累的 15 万行会让日志页查询聚合 10 秒以上；实测清理后从 8.2 秒降到 0.6 秒。该压缩只在启动时执行一次，日常不会删除近期历史。
- HDR 视频改为「先转换、显示真实进度、完成后播放」：HDR 色调映射在纯 CPU 上只有约 1–1.4 倍实时速度，边转边播永远追不上播放、也无法向前跳转。现在 HDR 走完整的转换流程（可看到百分比进度），完成后播放完整文件，**支持任意进度拖动**；SDR/重封装仍保持边转边播。
- HDR 转码参数优化：自动线程（原来固定 2 线程）＋ `superfast` 预设，实测从约 1.1 倍实时提升到约 2 倍，等待时间明显缩短。
- 硬件编码只用于非 HDR 内容：HDR 需要 CPU 色调映射，且该 GPU 驱动在 HDR 硬编路径上会挂起（已由停滞看门狗兜底）。

Docker 镜像：`posase/pimg:v1.0.47`，仅支持 `linux/amd64`。沿用 schema 30，不新增数据库迁移。升级步骤见[部署与升级](../deployment.md#升级已有实例)。
