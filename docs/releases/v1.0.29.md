# v1.0.29

修复图库预览误抢占归档，以及重试反复校验已完成分片的问题。

- 缓存缩略图和批量预览查询不再立即取消闲时归档；短时原图读取沿用 200 毫秒宽限，持续传输和预览重建仍可让归档让位。写入、删除、移动等操作保持立即让位。
- 中断或重启后，内容、布局和存储策略匹配的已验证远端分片直接复用，不再逐片重新下载校验。新分片首次写入、上次未完成的校验，以及手动校验仍完整回读。
- 本地副本检查存储文件大小和修改时间；变化时重新完整校验。旧版加密本地分片缺少修改时间记录时，首次恢复仍完整校验一次，再保存记录。
- 沿用单个闲时同步通道、工作空间上限、网络普通／加速限速与独立本地复制限速，不调整现有配置。

Docker 镜像：`posase/pimg:v1.0.29`，仅支持 `linux/amd64`。沿用 schema 30，从 v1.0.28 升级不新增迁移；保留原数据卷、运行卷、配置、密钥、会话与来源挂载，仅替换镜像。升级步骤见[部署与升级](../deployment.md#升级已有实例)。实际归档吞吐仍需更新线上后观察。
