# v1.0.55

修复文件收藏在容器重建、重新进入文件页或切换目录后首次打开失败的问题。

## 修复

- 收藏直接按保存路径读取当前文件元数据，不再只在目录第一页中查找。即使索引尚未建立、文件不在前 200 项或被当前筛选条件排除，也能打开仍然存在且可读取的图片和视频。
- 修复切换目录时，用上一目录的列表提前判定收藏失效的竞态。目录读取较慢时，已打开的收藏预览不会被新目录的加载状态清除。
- 连续点击收藏、转去其他页面、打开普通文件或开始导入时，取消旧的收藏读取，防止迟到的响应覆盖新的操作。
- 收藏目录与文件类型按当前文件系统识别；特殊字节路径和 Windows 根目录父路径由服务端解析。原有管理员权限、符号链接限制及源文件只读检查保持。
- 文件确实不存在、暂时不可读取或网络失败时给出对应错误，保留收藏以便恢复后重试。

## 升级

- Docker 镜像：`posase/pimg:v1.0.55`，平台 `linux/amd64`。
- 数据库仍为 schema 31，无新增迁移，不需要删除收藏、重建媒体数据或重新导入源文件。
- 使用原数据、运行目录及媒体挂载升级即可；刷新旧标签页后使用本版本界面。
- 此修复只读取单个文件的元数据，不因点击收藏创建索引、缩略图或导入任务。

升级步骤见[部署与升级](../deployment.md#升级已有实例)。
