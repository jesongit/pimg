# v1.0.38

恢复在查看器原图上直接右键或手机长按的浏览器原生操作，移除单独的手动复制窗口，并将全站操作反馈统一为不挤动页面的顶部飘字。

- 图片不再被透明视频手势层遮挡，原图元素保留原生右键／长按菜单。放大后的拖动达到移动阈值才接管指针，保留静止按压；视频左右定位和双击播放／暂停继续保留。
- 删除「手动复制原图」窗口。普通 HTTP 或浏览器不支持图片剪贴板时，复制按钮仅显示飘字，不自动下载、转换图片或打开新窗口。先查看原图，再在画面上右键或长按选择浏览器的复制图片功能；支持的 HTTPS／localhost 环境继续提供一键原图复制。
- 全站 80 处声明式页面反馈及现有操作通知统一为顶部居中的轻量飘字，覆盖保存、复制、读取失败、校验和重试等场景。反馈通过独立浮层呈现，不再撑开表单、底栏、弹窗或图片区域；手机位置避开顶部关闭按钮。
- 飘字在弹窗和全屏中保持可见；短提示自动消失，悬停／聚焦可暂停计时，带恢复操作的反馈保留重试入口。长消息、上传进度与任务详情入口继续可用。F8 聚焦通知，Tab 切换通知操作；普通模式下 Esc 关闭当前通知，全屏时 Esc 优先退出全屏。
- 图片缩放拖动、视频播放中按住定位、静音继承、倍速切换、全屏切图及退出后恢复底栏的行为保持一致。

Docker 镜像：`posase/pimg:v1.0.38`，仅支持 `linux/amd64`。沿用 schema 30，无新增数据库迁移；升级保留账号、密钥、Telegram 会话、原件、存储与代理额度配置。升级步骤见[部署与升级](../deployment.md#升级已有实例)。

原生菜单的项目和可用操作由浏览器／系统决定；手机实机长按、QQ／微信客户端实际粘贴和真实 TG／R2 提供方未验收。本次发布不自动更新已有部署。
