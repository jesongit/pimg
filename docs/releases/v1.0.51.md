# v1.0.51

修复部分视频无法播放的缓存残留，并给解压按钮加上实时进度。

- 修复：流式转换中断后残留的 `.building` 过渡文件此前永不清理，会导致后续播放该文件时缓存状态错乱而无法播放。现在启动清理时，无活跃流的 `.building` 孤儿文件会被移除；并为播放失败路径补上「哪个文件、何种模式、是否流式」的运行日志，便于定位。
- 解压按钮：点击后立即变为「解压中 x%」（解析 7z 进度），解压完成或失败自动恢复并提示；同一压缩包解压中不可重复点击，支持轮询实时进度。
- 新增解压状态查询接口 `GET /api/admin/file-browser/extract?path=…`。

Docker 镜像：`posase/pimg:v1.0.51`，沿用 schema 30。升级步骤见[部署与升级](../deployment.md#升级已有实例)。
