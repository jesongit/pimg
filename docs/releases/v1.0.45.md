# v1.0.45

修复流式转码在高负载机器上启动缓慢导致播放直接失败的问题。

- 修复：转换输出文件此前由 ffmpeg 在转码实际启动时才创建；机器被后台任务占满时启动可能超过 10 秒，播放端等待超时直接报「视频暂时无法播放」。现在转换队列建立时就创建输出文件，播放端挂载后**无限等待转换推进**（直到用户离开或转换完成），与旧版「能放只是慢」的等待语义一致，且随时可以中途离开。
- 转换重启（截断重建）时播放端读取位置自动回绕，不会卡在旧偏移上。

Docker 镜像：`posase/pimg:v1.0.45`，仅支持 `linux/amd64`。沿用 schema 30，不新增数据库迁移。升级步骤见[部署与升级](../deployment.md#升级已有实例)。
