# v1.0.34

修复非 UTF-8 的 Linux 目录名导致索引扫描失败，以及后台更新期间「更新索引」按钮无法点击的问题。

- 已保存监听目录后，即使正在首次建立索引、增量更新或带有扫描错误，也能再次提交更新请求。只有没有已保存目录或正在提交请求时，按钮才会禁用。
- 请求成功后明确显示已提交反馈；提交失败显示原因并允许重试。修改监听设置会清除旧的提交反馈。
- 修复快速清空或修改监听配置时扫描与监听关闭之间的竞争，避免索引任务无法正常退出。
- 沿用后台的合并队列和单个扫描任务，重复点击不会同时启动多个扫描，也不会中断当前扫描。当前扫描完成后处理排队的完整校对。
- Linux 扫描支持非 UTF-8 的原生文件名，索引缓存和浏览器传递保留原始路径字节，避免文件被漏扫、不同文件被混同或扫描成功后无法打开。支持目录导航、展开搜索、查看、下载及显式导入，并在重启后继续使用。
- 无法显示的名称字符使用替代字符展示，源路径仍精确定位，不需要改名素材。保留上级目录穿越、NUL 及符号链接检查，源文件保持只读。

Docker 镜像：`posase/pimg:v1.0.34`，仅支持 `linux/amd64`。沿用 schema 30，保留原有监听目录、缓存、配置及所有数据挂载。从 v1.0.33 升级后，可在「设置 → 文件索引 → 已保存目录的状态」点击「更新索引」，无需清空或重新保存监听目录。升级步骤见[部署与升级](../deployment.md#升级已有实例)。
