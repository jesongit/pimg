# v1.0.57

点击收藏栏的文件或文件夹后，顶部路径和文件列表自动切换到对应目录。

- 收藏的文件夹进入该目录；收藏的文件进入其所在目录，需要预览时再从列表打开。
- 收藏栏、收藏分组及「更多收藏」中的条目采用相同行为。
- 跳转时清除搜索、文件类型筛选和递归展开状态，保留排序，避免目标内容被隐藏。
- 继续按实际来源解析路径，兼容特殊文件名；连续点击以最后一次为准，手动导航取消尚未完成的跳转。失效收藏保留当前目录并提示错误。

Docker 镜像为 `posase/pimg:v1.0.57`，平台 `linux/amd64`。数据库仍为 schema 31，无新增迁移。保留原数据、运行缓存及媒体挂载升级，刷新页面即可使用。
