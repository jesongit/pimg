# v1.0.32

新增可配置的文件夹监听索引，加快大目录浏览、搜索和展开；同时包含 v1.0.31 的本地视频加载优化。

- 新增「设置 → 文件索引」，每行填写一个服务器或容器内的绝对目录，保存立即生效并包含子目录。默认空列表，不监听、不扫描、不创建索引库；清空并保存即可停止监听。
- 首次在后台建立独立的文件信息索引，之后普通浏览、搜索、十种排序和展开直接查询索引，分页只读取 200 项。文件变更更新对应记录，新增目录扫描新增子树；重启复用已有索引并补扫，定期每 10 分钟校对，也可手动更新。
- 建立中、更新中和异常状态清晰显示；索引更新保留当前选择和查看状态，多页加载使用版本校验，防止混用不同次序。已配置索引的展开不再受即时扫描 5 万项限制；目录数、层级、扫描时间和索引空间边界见[使用说明](../usage.md#文件浏览与导入)。
- 索引只保存文件信息，不复制、转码或导入媒体。源目录保持只读，实际查看、下载和导入继续校验路径、权限和源文件版本；普通账号不能浏览服务器目录。
- 包含 v1.0.31 的视频改进：支持 HEVC 的浏览器可直接播放兼容的 MP4/M4V；Linux 视频兼容处理直接读取经过校验的只读源文件句柄，省掉完整输入复制。必要的转码仍需生成兼容输出后播放，并显示实际转换进度；目前不支持边转码边播放。

Docker 镜像：`posase/pimg:v1.0.32`，仅支持 `linux/amd64`。沿用 schema 30，从 v1.0.30 或 v1.0.31 升级不新增迁移；保留原数据卷、运行卷、配置、密钥、会话与素材只读挂载，仅替换镜像。升级后在「设置 → 文件索引」配置目录才会启用索引，原有同步限速设置保持不变。详见[部署与升级](../deployment.md#升级已有实例)。
