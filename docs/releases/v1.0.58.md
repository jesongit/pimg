# v1.0.58

优化收藏栏的打开与定位操作：收藏文件夹直接进入，收藏文件单击打开、双击定位所在目录。

- 点击收藏的文件夹直接进入该文件夹；图片和视频收藏单击打开预览，保留当前路径、搜索、类型筛选与展开状态。
- 双击文件收藏跳转到文件所在目录，清除搜索、类型筛选及递归展开状态，保留排序。其他暂不支持预览的文件同样可双击定位。
- 收藏栏、分组、嵌套分组和「更多收藏」采用相同行为。文件单击短暂等待以区分双击，菜单在动作确定后关闭，避免预览截获第二次点击。
- 键盘 Enter 立即打开，Shift+Enter 定位目录；切换目录、点击其他控件、拖动、移除或按 Escape 会取消待执行的单击预览。
- 继续通过实际来源解析文件和父目录，保留权限、特殊文件名、请求取消及失效收藏提示。

Docker 镜像为 `posase/pimg:v1.0.58`，平台 `linux/amd64`。数据库仍为 schema 31，无新增迁移。保留原数据、运行缓存及媒体挂载升级，刷新页面即可使用。
