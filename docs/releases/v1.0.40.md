# v1.0.40

增加可由诊断令牌直接读取的 TG 连接诊断，保留连接失败的阶段和安全错误类型，避免长时间“正在连接”时只能看到笼统的“请先授权”。

- 新增只读 `/api/diagnostics/telegram`：返回当前连接与授权状态、运行时状态、会话文件是否存在、实际 TCP/代理拨号次数、成功次数、在途拨号、最近就绪时间、最近失败和最多 16 条失败历史。
- 接入 TG 底层断线回调与实际拨号观测，区分 DNS、TCP 拒绝、网络不可达、超时、连接关闭、代理 TLS、代理认证/隧道拒绝、代理额度、会话存储和协议错误。界面继续自动重连，同时显示安全的失败原因；连接尚未建立时，任务不再统一提示为未授权。
- 诊断仅返回代理使用方式和协议等固定字段，不返回代理地址、账号、密码、API Hash、手机号、群/账号标识、会话内容或路径。读取不触发连接测试、重连、登录、账号绑定或额度保存；管理员接口及写操作权限保持原有边界。
- Linux 性能采样增加磁盘实际读写字节、字符 I/O 和主/次缺页累计计数，帮助复查首次页面请求的磁盘/缓存成本。应分别比较首次和后续请求，指标不能替代线上验收。

Docker 镜像：`posase/pimg:v1.0.40`，仅支持 `linux/amd64`。沿用 schema 30，不新增数据库迁移或会话格式变更。升级步骤见[部署与升级](../deployment.md#升级已有实例)。

本版补齐排障证据，不宣称已修复某个线上网络出口或会话故障；具体原因需在升级后读取新的连接诊断。本次发布不自动更新已有部署，真实 TG／R2 提供方仍需实际环境验收。
