# v1.0.49

补齐 /data 中出现的媒体扩展名支持。

- 新增视频扩展名识别：WMV（àx videox-ms-video，内含 VC-1/WMV3 转码兜底）、MPG/MPEG/MP2/VOB（MPEG 系）、OGV/OGM（Ogg 视频）、RM（RealMedia）。浏览器不支持的仍走重封装或转码兜底。
- `.qt`、`.3gp`、`.3g2` 上一版已加入，本版再补 mpeg 等常见容器。
- 规则保持：能直连/重封装的走原格式（HDR 亦然，浏览器支持即直出），否则转码为 H.264/AAC MP4 兜底。

Docker 镜像：`posase/pimg:v1.0.49`，沿用 schema 30。升级步骤见[部署与升级](../deployment.md#升级已有实例)。
