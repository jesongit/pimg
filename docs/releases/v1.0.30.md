# v1.0.30

文件页改为文件管理器式列表，支持按时间排序，并可展开子文件夹直接浏览全部图片和视频。

- 文件夹和文件统一显示为详情列表，展示名称、类型、大小、创建时间和修改时间；支持名称、大小、类型及两种时间的升降序排序，排序覆盖完整目录后再分页。
- 创建时间读取文件系统实际创建时间；文件系统未提供时显示“—”，排序时始终放在已知时间之后。
- 点击图片或视频后直接读取源文件并尝试播放，保留格式兼容处理和失败重试，省去二次加载操作。
- 当前目录收藏星标左侧新增“展开所有文件”图标，将当前文件夹及所有子文件夹中的图片和视频平铺显示，并保留来源路径、搜索、排序和分页；再次点击恢复文件夹浏览。
- 列表只读取文件元数据，来源目录继续只读；展开扫描有数量、时间和缓存上限，分页使用目录快照，避免重复遍历。管理员访问限制、收藏、框选和复制导入到相册保持可用。

Docker 镜像：`posase/pimg:v1.0.30`，仅支持 `linux/amd64`。沿用 schema 30，从 v1.0.29 升级不新增迁移；保留原数据卷、运行卷、配置、密钥、会话与来源挂载，仅替换镜像。升级步骤见[部署与升级](../deployment.md#升级已有实例)。本版本不修改已有同步限速设置。
