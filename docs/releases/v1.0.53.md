# v1.0.53

文件浏览器的收藏栏重做，并新增类型筛选。

- 收藏栏：位于搜索下方，按管理员账号保存在服务端（多设备一致）；文件夹与收藏项支持删除，删除只移除收藏记录，不影响磁盘文件。
- 收藏入口：文件列表每行末尾新增收藏星标，可收藏文件夹或文件；已收藏点击实心星标直接取消。底部批量栏新增「收藏选中」，仅在有勾选时出现，可一次收藏多个文件夹/文件。
- 收藏文件夹：收藏栏最右侧固定「新建收藏文件夹」图标；收藏栏支持在栏内拖动排序、拖入文件夹；「更多」弹层中的文件夹以向左子菜单展示，子菜单内可继续拖动/移入子文件夹。
- 旧收藏迁移：首次进入时自动把浏览器本地旧收藏迁移到服务端，失效路径会被跳过。
- 筛选：搜索右侧新增「筛选」，可只看全部/文件夹/图片/视频/其他文件，按服务端过滤，分页与总数准确，并与搜索、排序、展开和文件索引兼容。
- 修复：本机开发环境下文件页默认目录从写死的 `/data` 改为后端默认导入目录（线上仍为 `/data`）。

Docker 镜像：`posase/pimg:v1.0.53`，schema 31（新增收藏表）。升级步骤见[部署与升级](../deployment.md#升级已有实例)。
