# v1.0.36

统一相册详情和文件预览的图片／视频操作区，新增原图复制，简化视频控制与手势，并修复全屏切换文件时退出全屏的问题。

- 底部文件按钮居中；图片和视频使用固定的六个媒体按钮位置，切换时保持操作区高度。图片的放大、缩小、适应窗口、原图和复制按钮都位于底栏，不遮挡图片。
- 新增「复制原图」：读取完整原件，以原图尺寸的 PNG 图片写入剪贴板，供 QQ、微信等应用粘贴；不是复制链接或缩略图。需要 HTTPS 或 localhost，以及浏览器的图片剪贴板权限。HEIC/HEIF 沿用现有解码能力，无法解码时明确报错并保留原件下载。
- 视频改用底栏播放／暂停、前后定位、倍速、静音和全屏按钮，移除浏览器原生控制栏。只有视频在画面区域底边显示细进度条，支持点击或拖动定位，不占额外布局高度。
- 倍速点击直接循环切换，不展开菜单。音量按钮改为静音开关：每次重新打开详情默认静音；同次详情内前后切换文件、经过图片时继承当前声音状态。相册详情与文件浏览器行为一致。
- 保留双击／双击触控播放暂停；视频左右拖动改为快进／快退，播放中定位后，即使仍按住也继续播放。移除鼠标／触控长按快退、临时加速、拖动调速和上下调节亮度／音量。键盘快捷键继续保留。
- 正常查看时，上一张／下一张两侧点击区域各缩小为画面宽度的 1/6。放大图片沿用较小边缘按钮以保留拖动空间。
- 修复图库、相册详情和文件浏览器在全屏切换下一张时退出全屏；全屏下仍可使用底部媒体控制、加载和重试按钮。

Docker 镜像：`posase/pimg:v1.0.36`，仅支持 `linux/amd64`。沿用 schema 30，无新增数据库迁移；升级保留账号、密钥、Telegram 会话、原件、存储与代理额度配置。升级步骤见[部署与升级](../deployment.md#升级已有实例)。
