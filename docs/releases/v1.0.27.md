# v1.0.27

新增管理员专用“文件”页面，从顶部菜单进入；图库移除重复的“导入”入口。

- 沿服务器或容器中的原目录结构浏览图片、视频；路径可点击，上一级和收藏夹采用图标按钮。
- 收藏夹以简洁文件夹名称列表展示，支持取消收藏，沿用本浏览器按账号保存的已有收藏。
- 支持按名称、文件大小和文件类型升序／降序排列，文件夹始终在前；整个目录先排序再分页，搜索、目录切换和加载更多保持排序。
- 源文件只读，不提供改名、移动或删除。图片直接读取原件，视频点击后准备播放；不兼容格式按需使用 HEIC 解码、图片兼容转换、视频重封装或转码，缓存保存在 PIMG 运行目录。
- 可将单个文件、多选文件或当前目录复制导入内部相册，沿用明确选择目标、预览后开始、重复跳过及任务恢复流程，保留源文件。

图片支持 JPG、JPEG、PNG、GIF、WebP、AVIF、BMP、HEIC、HEIF；视频支持 MP4、M4V、MOV、WebM、MKV、AVI、FLV、TS、MTS、M2TS。普通账号不能浏览服务器目录。Docker 只能访问容器已挂载路径，建议素材目录只读挂载，并用 `PIMG_IMPORT_DIR` 设置默认来源目录。详见[使用说明](../usage.md#文件浏览与导入)。

Docker 镜像：`posase/pimg:v1.0.27`，仅支持 `linux/amd64`。沿用 schema 30，从 v1.0.26 升级不新增迁移；保留原数据卷、运行卷、配置、密钥、账号会话及来源挂载，仅替换镜像。不会自动更新已有实例，不应删除或重新初始化数据卷。
