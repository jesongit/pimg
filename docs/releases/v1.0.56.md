# v1.0.56

文件列表每行在收藏星标左侧新增下载图标，可直接下载原文件。

- 图片、视频、文本、压缩包等普通文件均可下载；目录行保留收藏操作。
- 下载沿用原文件名和原始字节，不触发预览、解压、转码、导入或行选择，保留 HTTP Range 与断点续传支持。
- 桌面沿用列表的图标样式；手机下载和收藏按钮均提供至少 44px 触控区域，窄屏及长文件名保持操作可见。
- 下载仍需管理员身份，并沿用路径、符号链接、文件类型和版本检查；普通文件不会因此获得在线预览能力。

Docker 镜像为 `posase/pimg:v1.0.56`，平台 `linux/amd64`。数据库仍为 schema 31，无新增迁移。按原数据和媒体挂载升级，刷新页面即可看到新入口。
