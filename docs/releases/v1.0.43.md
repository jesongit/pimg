# v1.0.43

兼容视频转码改用 Intel 核显（VAAPI）硬件编码，HDR/4K 转码接近实时。

- 转码时优先使用 Intel 核显硬件编码（`h264_vaapi`，CQP 质量 23），软件 x264 作为自动回退：容器内探测到 `/dev/dri/renderD128` 即启用，硬件初始化失败且尚未向客户端输出任何字节时自动退回软件编码，不影响无核显的部署。
- 流式播放保持不变：转码边转边播，退出观看后随连接断开自动终止。
- 运行镜像新增 `intel-media-driver`；容器需以 `--device /dev/dri` 运行才能启用硬编（部署文档已更新）。
- 文件浏览排序：日期排序（修改/创建）扩展到文件夹（文件夹仍分组最前，组内按所选日期键），即时扫描与索引路径一致。

Docker 镜像：`posase/pimg:v1.0.43`，仅支持 `linux/amd64`。沿用 schema 30，不新增数据库迁移。升级步骤见[部署与升级](../deployment.md#升级已有实例)。
