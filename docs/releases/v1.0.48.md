# v1.0.48

修复 .qt/.MOV 等 QuickTime 视频无法播放，并让支持 HEVC 的浏览器直接播放 HDR（不再慢速转码）。

- 新增 `.qt`、`.3gp`、`.3g2` 扩展名识别为视频（此前 `.qt` 被当作未知文件，点击直接报「此格式不支持在线查看」）。
- HDR 视频优先直连/重封装：浏览器能解码 10-bit HEVC（Edge/Chrome 装 HEVC 扩展、Safari 等）时，MP4 直接播放、MOV/QT/MKV 仅做秒级重封装（stream copy），**不再整段转码**——打开即播、支持任意拖动。只有浏览器明确不支持 HEVC 10-bit 时才回退转码（此时显示真实进度，完成后可拖动）。
- 转码兜底路径中，HDR 输出限制在 1080p 以内：实测本机 4K HEVC 10-bit 纯软件解码仅约 0.19 倍实时，4K HDR 转码在中低端 CPU 上不可行，降分辨率是唯一可用方案。

Docker 镜像：`posase/pimg:v1.0.48`，仅支持 `linux/amd64`。沿用 schema 30，不新增数据库迁移。升级步骤见[部署与升级](../deployment.md#升级已有实例)。
