# v1.0.52

文件浏览器交互与解压能力增强。

- 解压：rar（含 RAR5）改用 bsdtar（libarchive）解压，7z 仍用于 zip/7z/iso；工具失败自动级联回退，并把实际报错带回界面，不再只显示「code 2」。
- 文件排序：移除工具栏的排序下拉（表头各列已可排序），只保留表头排序。
- 表格：表头增加「全选/反选」复选框，作用于当前列表全部项（含文件夹；展开视角则含所有展开项）。
- 操作菜单：「导入当前目录」旁新增「操作」菜单，含「新建文件夹」（弹窗输入名称、在当前目录创建）和「硬链接选中项」（显示选中文件/文件夹数量、填写目标绝对路径，直接硬链接文件、文件夹递归硬链接其中文件）。
- 移除收藏功能（收藏夹菜单与收藏星标按钮）。

Docker 镜像：`posase/pimg:v1.0.52`，沿用 schema 30。升级步骤见[部署与升级](../deployment.md#升级已有实例)。
