# v1.0.31

修复文件页展开范围、切换目录及本地视频打开缓慢的问题。

- 文件系统根目录禁用“展开所有文件”；切换路径、上一级、祖先路径、收藏及浏览器历史导航均恢复逐层浏览，需要时重新展开，同一目录刷新保留模式。
- 普通目录分页仅保留所需排序范围，超过 5 万项时仍可浏览首页；递归扫描达到数量、层级或元数据上限时保留已扫描结果，并明确提示范围不完整，可进入更小的子文件夹查看完整内容。
- 支持 HEVC 的浏览器直接播放 SDR、8 位 HEVC＋兼容音轨的 MP4/M4V，避免不必要的整段转码；原生播放失败后自动选择兼容处理。不支持 HEVC 的浏览器仍需生成兼容视频。
- Linux 视频兼容处理从经过校验的只读文件句柄读取，不先复制完整原件；只有音轨不兼容时保留原画面，只转换音轨。必要的视频转码使用更快的预设，并限制处理线程。
- 准备状态区分等待、复制、封装和转码，转换过程显示实际进度，避免始终显示 0%；源文件、原件下载及导入字节保持不变。

Docker 镜像：`posase/pimg:v1.0.31`，仅支持 `linux/amd64`。沿用 schema 30，从 v1.0.30 升级不新增迁移；保留原数据卷、运行卷、配置、密钥、会话与来源挂载，仅替换镜像。升级步骤见[部署与升级](../deployment.md#升级已有实例)。本版本不修改已有同步限速设置。
