# v1.0.44

修复流式转码被停止读取的播放器卡死的问题，并修正流式播放的进度条。

- 修复：转码器此前与播放连接串在一起，播放器退出/停止读取但连接未断时，写回被 TCP 背压卡死，转码整体停摆，后续打开同一视频的请求在单飞队列里无限等待（表现为「加载半天」）。现在转码器只写缓存文件、永不阻塞；播放器从「正在增长的转换文件」独立拉流，多个观看者互不干扰，暂停播放也不影响转码推进；所有观看者离开后才取消转换。
- 修复：流式播放的进度条此前用「已转换部分的时长」做分母，会随转换推进回退；现在使用服务端探测的真实总时长，转换期间进度条稳定、方向正确，拖动边界也按总时长计算。
- 转换完成的版本仍然整段缓存（默认 24 小时），重复打开免转码、可完整拖动；中途退出未完成的转换作废，重开时以核显速度重新开始。

Docker 镜像：`posase/pimg:v1.0.44`，仅支持 `linux/amd64`。沿用 schema 30，不新增数据库迁移。升级步骤见[部署与升级](../deployment.md#升级已有实例)。
