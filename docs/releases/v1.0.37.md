# v1.0.37

修复详情全屏时仍显示底部操作区，以及普通 HTTP 地址下链接、令牌无法复制和原图复制没有可见反馈的问题。

- 全屏隐藏标题、底部按钮、标签／状态、视频进度线和展开的功能面板，只保留画面、前后切换及顶部退出全屏入口。加载失败时仍可在画面中央重试；退出全屏恢复原有操作区。
- 链接与令牌复制增加文本选择回退，支持局域网普通 HTTP 地址，以及新版文本剪贴板接口拒绝时的复制。回退在当前弹窗内完成，并恢复焦点和原选择。
- 原图复制的准备、成功和错误反馈直接显示在详情内，避免被详情弹层遮挡。支持的 HTTPS／localhost 环境仍从完整原件解码，以原图尺寸的 PNG 写入图片剪贴板。
- 普通 HTTP 或不支持图片剪贴板接口的浏览器，点击「复制」会打开完整原图，供右键（手机上长按）选择「复制图片」。此方式需要手动选择浏览器菜单；不会把链接或 HTML 当成图片复制成功。一键复制图片仍需要 HTTPS 或 localhost 及浏览器支持。

Docker 镜像：`posase/pimg:v1.0.37`，仅支持 `linux/amd64`。沿用 schema 30，无新增数据库迁移；升级保留账号、密钥、Telegram 会话、原件、存储与代理额度配置。升级步骤见[部署与升级](../deployment.md#升级已有实例)。

浏览器内的自动化检查不能代替 QQ／微信客户端的实际粘贴验收；本版未完成客户端或实体手机验收。本次发布不自动更新已有部署。
