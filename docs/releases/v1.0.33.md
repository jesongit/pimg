# v1.0.33

修复 Linux 索引扫描把合法文件夹名称误判为非法相对路径，导致“部分索引未能更新：请选择导入根目录内的相对路径”的问题。

- Linux 文件名中的冒号与反斜杠按普通字符处理，支持含这些字符的监听目录、子目录及源文件，索引扫描、查看、导入及增量更新沿用同一套平台规则。Windows 继续拒绝盘符、备用数据流及反斜杠分隔符形式的相对路径。
- 修复 Linux 展开搜索中把文件名中的反斜杠替换为目录分隔符的问题；Windows 的路径分隔符搜索保持原行为。
- 扫描或增量更新失败时，错误会指出具体子目录或路径，便于定位读取权限和名称问题。
- 保留绝对路径／上级目录穿越检查及符号链接拒绝规则。索引与查看保持源文件只读，不改名、不移动、不删除素材。

Docker 镜像：`posase/pimg:v1.0.33`，仅支持 `linux/amd64`。沿用 schema 30，从 v1.0.32 升级保留原配置、数据卷、运行卷、缓存及素材挂载。现有监听目录会在启动后自动重新校对；也可在「设置 → 文件索引」点击「更新索引」，无需删除图库数据或重建监听设置。升级步骤见[部署与升级](../deployment.md#升级已有实例)。
