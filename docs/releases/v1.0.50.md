# v1.0.50

音频以伪视频方式播放，压缩包支持后台智能解压，文件页默认打开 `/data`。

## 音频播放
- 新增音频扩展识别为可播放视频：mp3、flac、wav、m4a、aac、ogg、opus、wma、aiff、mka。
- 音频在播放器中以「伪视频」形式呈现：底层转成带单一黑帧的 MP4（AAC 音频），画面上叠加一条播放中的频谱动画，暂停时动画停止；支持进度拖动、倍速、音量等现有视频控制。
- 打开即流式转换播放，不等待全量转完。

## 压缩包智能解压
- 支持 zip / rar / 7z / iso，容器镜像新增 p7zip。
- 文件列表里归档文件右侧出现解压按钮，点击后**后台非阻塞解压**，一次一个。
- 智能落位：压缩包内是单一文件夹 → 直接解为该同名目录；否则在源目录旁先建一个与压缩包同名的文件夹再解入。
- 解压进度/状态保存在内存；后台进行，不阻塞浏览。

## 其它
- 文件浏览初始目录改为 `/data`（无保存路径时）。
- 附带上一版的 HDR 直连/重封装、`.qt`/`.3gp` 识别等。

Docker 镜像：`posase/pimg:v1.0.50`，仅支持 `linux/amd64`。沿用 schema 30。升级步骤见[部署与升级](../deployment.md#升级已有实例)。解压依赖容器内 p7zip，已随镜像提供。
