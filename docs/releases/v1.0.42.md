# v1.0.42

修复 v1.0.41 流式兼容转换的两个致命缺陷，并改进文件浏览体验。

- 修复流式兼容转换没有传入输入文件（ffmpeg 收不到 `-i` 参数），导致所有需要兼容处理的视频在 v1.0.41 上无法播放；该路径此前缺少跨平台端到端测试，现已补齐并在 Windows/Linux 双平台运行。
- 修复 ffmpeg 8/9 将 `frag_keyframes` 更名为 `frag_keyframe` 后流式输出参数非法的问题。
- 流式转换失败会记录运行日志（含文件名与模式），不再静默失败。
- 文件浏览的日期排序（修改/创建）现在同样作用于文件夹：文件夹仍分组在最前，但组内按所选日期键排序；大小/类型对文件夹仍按名称（文件夹没有有意义的大小和扩展名）。即时扫描与索引两种路径一致。
- 视频进度条在鼠标点击后不再显示白色焦点框（键盘 Tab 聚焦时保留），点击后释放焦点，方向键快捷键不再被进度条吞掉。
- 播放视频时在画面上右键可直接切换静音/取消静音，并显示状态提示。

Docker 镜像：`posase/pimg:v1.0.42`，仅支持 `linux/amd64`。沿用 schema 30，不新增数据库迁移。升级步骤见[部署与升级](../deployment.md#升级已有实例)。
